# Security

Shrike for iPhone holds seed words and signs Bitcoin transactions, and it hasn't been audited. If you find a way to read a seed, sign something the user didn't approve, send to the wrong address or the wrong chain, or make a transaction replayable when the app says it's protected, please report it privately so it can be fixed before it's public:

- On GitHub, open the repository's **Security** tab and choose **Report a vulnerability**.

Please include the app version (Settings, at the bottom), the iPhone and iOS version, and the steps to reproduce it. Don't include real seed words, passwords or node addresses.

Ordinary bugs can go in the issue tracker.
